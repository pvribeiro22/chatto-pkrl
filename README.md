# chatto-pkrl

Bot pessoal de WhatsApp — número dedicado, uso próprio, sem multi-tenant.

Faz figurinha a partir de imagem, conversa com persona por contato, lembra de mensagens
recentes e dispara lembretes agendados.

**Status:** planejamento fechado, nenhum código escrito. O escopo e a ordem de construção
estão em [`docs/decisoes-e-plano.md`](docs/decisoes-e-plano.md).
